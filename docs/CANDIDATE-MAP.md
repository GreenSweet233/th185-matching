## 四、结论：P1 的剩余空间

### 乐观估计


### 现实约束

## 附：`function_extent` 的片段问题

典型片段：

```asm
8b4510          mov  eax, [ebp+0x10]     ; ★ 读 [ebp+..] 但没有 push ebp
ff30            push dword [eax]
e8 ad480000     call 0x4A2533
59              pop  ecx
c3              ret
```

判据：**无 `push ebp` / `mov ebp,esp` 却读 `[ebp+N]`**（N > 8）。

这 60 个应该是同一段代码的不同 `call` 目标，被误识别为独立函数。
